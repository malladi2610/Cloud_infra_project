# arXiv Edge AI Example Profile

This is a disabled-by-default example profile.

## Enable
1. Open `examples/arxiv_edge_ai/profiles/arxiv_edge_ai.json`
2. Change `"status": "planned"` to `"status": "active"`
3. Restart app service so profile cache reloads.

## Workflow Import
Import this workflow in n8n:
- `examples/arxiv_edge_ai/workflows/arxiv_edge_ai_workflow.json`

## Reference Taxonomy
The example reference taxonomy is served from:
- `examples/arxiv_edge_ai/reference-site/edge-ai-taxonomy.json`
